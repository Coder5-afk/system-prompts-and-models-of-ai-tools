## 4. Practice health (for EA practice assessments)

Score 1 to 5 with evidence.

| Objective | Questions | Score | Evidence |
| --- | --- | --- | --- |
| **Shared alignment** | Are stakeholders known and engaged? Are priorities agreed? Do decisions stick, or get relitigated? | | |
| **Embedded and accessible** | Can engineers find standards and decisions within a minute, in their own tools? Are artefacts current? | | |
| **Enable and enforce** | Are there templates and golden paths? Are standards few, clear and automated where possible? Is the exception process working? | | |
| **Proactive and reactive** | Is there time for strategic work? Are inflection points (AI, cloud) being shaped early? | | |

Manifesto check:
- [ ] Decisions are made with capability and domain context
- [ ] Direction is tangible (reference implementations, docs as code)
- [ ] Behaviour is driven by making the right path easy
- [ ] Frameworks are adapted, not followed rigidly
